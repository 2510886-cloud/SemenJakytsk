Документальная версия 2, 29 октября 2026 года. 14 хронологических записей, 8 отобранных карточек отзывов, 13 источников документального раздела. Истории посетителей и коллег, публикации и реестровые сведения различаются по происхождению и ограничениям.

- Сайт: public/index.html — автономный HTML со встроенными стилями, данными и JavaScript.
- Исследовательский отчёт и ограничения: research-progress.md.
